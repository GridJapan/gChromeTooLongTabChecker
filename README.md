# TooLong Tab Checker（gChromeTooLongTabChecker）

読み込んでから決めた時間（既定 24 時間）を過ぎたタブを一覧にする Chrome の拡張機能です。一覧の行を押すと、そのタブの窓が前に出て、そのタブが選ばれます。

Gmail・スプレッドシート・Teams などのタブは、開いたままにしているとメモリを少しずつため込みます。Auto Tab Discard や Chrome のメモリセーバーは、表に出ているタブや、通知・接続を保っているタブを外せません。そうしたタブは何日も読み込まれたままになり、1 つのプロセスが 1〜2GB に育つことがあります。

この拡張機能で、そうしたタブをすぐ見つけて開けます。見つけたタブは、閉じて開き直すか、読み込み直してください。

## 動き

- タブがページを読み込んだ時刻を覚えます（同じページの中の移動は数えません）
- ツールバーのアイコンに、時間を過ぎたタブの数が出ます（5 分ごとに数え直します）
- アイコンを押すと、時間を過ぎたタブが古い順に並びます（経過時間・題名・何番目の窓か）。行を押すと、その窓が前に出て、そのタブが選ばれます
- 外れたタブ・まだ読み込まれていないタブは出しません（メモリを使っていないため）
- タブやグループは動かしません

0.1.0 は、時間を過ぎたタブを「TooLong」グループへ移していました。0.2.0 を入れると（更新でも入れ直しでも）、そのグループを片付けます。元のグループの記録が残っていればそこへ戻し、無ければグループの外へ出します。

外へは何も送りません。記録は Chrome の中（`chrome.storage.session`）にだけ置き、Chrome を終えると消えます。一覧のアイコンも、サイトへ取りに行かず、Chrome が手元に持っているものを使います。

## 入れ方

1. このリポジトリを clone します
2. Chrome のアドレスバーに `chrome://extensions` と入れて開き、右上の「デベロッパー モード」を ON にします
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このリポジトリの `src` フォルダを選びます
4. ツールバーのパズルのアイコンから「TooLong Tab Checker」をピン留めすると、アイコンと数が見えます

Chrome のプロファイルごとに入れてください。拡張機能はプロファイルごとです。

## 設定

一覧の下の欄で、時間（既定 24）を変えられます。

### すでに開いているタブの時刻

入れる前から開いていたタブ（と、拡張機能を入れ直した直後のタブ）は、読み込んだ時刻が分かりません。そのままでは、入れた時刻から数えます（実際より短く出ます）。

一覧の下の「すでに開いているタブの読み込み時刻を正確に読む」を押して許可すると、各ページの `performance.timeOrigin`（ページを読み込んだ時刻）を読みます。読むのはこの時刻だけです。許可は「すべてのサイト」になるので、要らなければ許可しなくても使えます。

## 使う権限

| 権限 | 使い道 |
|---|---|
| `tabs` | タブの一覧を読み、押したタブを選ぶ |
| `tabGroups` | 0.1.0 が作った TooLong グループを片付ける |
| `favicon` | 一覧に、Chrome が持っているサイトのアイコンを出す |
| `webNavigation` | ページを読み込んだ時刻を知る |
| `storage` | 設定と、読み込んだ時刻の記録 |
| `alarms` | 5 分ごとの確認 |
| `scripting`＋任意の「すべてのサイト」 | 許可したときだけ、すでに開いているタブの読み込み時刻を読む |

## 開発

```bash
npm test            # 判定と、作り物の chrome.* の上での動き（node だけで動く）
node tests/e2e.mjs  # 本物の Chromium（Chrome for Testing）に読み込ませて確かめる
```

`tests/e2e.mjs` は、使い捨てのプロファイルで、画面を出さずに（headless）動かします。ふだんの Chrome には触れません。Chrome for Testing は `npx playwright install chromium` で入れるか、場所を `CFT=…` で渡します。
